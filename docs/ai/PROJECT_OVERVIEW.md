# Telegram Favorites Assist — обзор проекта

## Цель

Веб-приложение для личного использования: импорт, обогащение и умная классификация постов из Telegram-чата «Избранное» (Saved Messages).

## Проблема

В «Избранное» накапливаются пересланные ссылки и заметки о сервисах и приложениях без структуры. Нужен каталог с категориями, метаданными и быстрым поиском.

## Целевой результат (MVP)

1. **Импорт** — первичная загрузка истории чата «Избранное» (текст, ссылки, медиа-метаданные).
2. **Обогащение** — Open Graph по URL, GitHub stars (если есть репозиторий), описание.
3. **Классификация** — автоматические категории через OpenAI (транскрибация, TTS, видео, монтаж и др.; список категорий не фиксирован).
4. **Синхронизация** — 2 раза в день проверка новых постов и автоматическая обработка.
5. **UI** — карточки сервисов, групповой и одиночный просмотр, поиск, фильтры по категории и дате, адаптивная вёрстка.
6. **Без авторизации** — v1 только для локального/личного использования.

## Вне scope v1

- Мультипользовательский режим и auth.
- Публичный деплой с защитой (планируется позже).
- Редактирование категорий вручную (может добавиться позже).

## Ключевые сущности

| Сущность | Описание |
|----------|----------|
| Post | Сообщение из «Избранное» (текст, дата, telegram message id) |
| Link | URL из поста с Open Graph и GitHub-метаданными |
| Service | Агрегированная карточка сервиса/приложения (может объединять несколько постов) |
| Category | Категория классификации (динамическая, задаётся AI) |

## Окружение

- Локальный запуск → деплой на сервер.
- Секреты: OpenAI API key, Telegram credentials (см. DECISIONS.md).
