# Конвенции проекта

## Память проекта

- Единственный источник истины — `docs/ai/`.
- Перед задачей читать все файлы памяти.
- После изменений кода обновлять `CURRENT_STATE.md`.
- Решения — в `DECISIONS.md`, краткая история — в `CHANGELOG_AI.md`.
- Не хранить в памяти: логи, stacktrace, временные гипотезы.

## Код

| Область | Правило |
|---------|---------|
| Backend | Java 21, Spring Boot 3.x, пакет `com.altacod.favorites` |
| Frontend | TypeScript, React 18+, Vite, функциональные компоненты |
| API | REST, JSON, версионирование через `/api/` |
| DB | Flyway/Liquibase миграции, snake_case в таблицах |
| Env | `.env.example` в корне; секреты не коммитить |

## Тесты

- Каждая фича — автотесты (JUnit 5 backend, Vitest frontend).
- Тесты запускаются при каждой сборке (`gradlew test`, `npm test`).
- Падающий тест — исправить баг, затем пересобрать.

## Git / PR

- Минимально инвазивные изменения.
- Без массовых рефакторингов без запроса.
- Commit только по явной просьбе пользователя.

## UI/UX

- Mobile-first, адаптивная вёрстка.
- Карточки: изображение, название, ссылки (app, repo), описание, GitHub stars, категория, дата добавления.
- Поиск + фильтры всегда доступны на главном экране каталога.

## Язык

- Код и комментарии: английский.
- UI: русский (основной пользователь).
- Документация памяти: русский.
